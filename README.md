# Fareed Ahmad Portfolio

Multi-page portfolio website for web development and AI video services.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Run locally

1. Extract this project ZIP.
2. Open a terminal in the extracted `fareed-ahmad-portfolio` folder.
3. Run `npm install`.
4. Run `npm run dev` and open the local URL printed by Vite.

## Build for hosting

Run `npm run build`. Vite writes the production-ready website to `dist/`.
Upload the contents of `dist/` to your static hosting provider.

To inspect the production build locally, run `npm run preview` after building.

## Portfolio admin

Open /admin.html while running the Vite development server to add AI video and website samples. Add a public media URL and optional cover image URL. This starter stores sample records in browser localStorage, so it is suitable for a local demo. A shared backend/CMS is required for edits to appear to all visitors on a deployed site.
